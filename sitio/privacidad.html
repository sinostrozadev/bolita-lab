Privacy Policy

Effective date: November 4, 2026 · Última actualización: 4 de noviembre de 2026

Who we are. Bolita Lab is a YouTube channel (youtube.com/@bolitalab) operated by its owner as an individual creator in Chile. Contact: sinostrozadev@gmail.com.

1. What this policy covers

This policy covers (a) this website and (b) the "Bolita Lab" API client, an internal software tool that uses YouTube API Services to upload and schedule videos on the channel owner's own YouTube channel. The API client is not offered to the public and has a single user: the channel owner.

2. Use of YouTube API Services

The Bolita Lab API client uses the YouTube Data API. By using it, the user also agrees to be bound by the YouTube Terms of Service and the Google Privacy Policy.

The API client authenticates through Google OAuth 2.0 with the scopes youtube.upload and youtube. It uses them only to: upload videos and thumbnails to the authorized channel, set their title, description, tags, category, language and scheduled publication date, and read basic information and statistics of that same channel and its videos.

3. Data we access, store and share

  • Authorized user data. The OAuth access and refresh tokens of the channel owner are stored locally, on the owner's own computer, in a file readable only by the owner. They are never transmitted to any third party and are used solely to call the YouTube API on the owner's behalf.
  • Channel and video data. Titles, IDs, publication dates and public statistics (views, likes, comments counts) of the owner's own videos may be stored locally to plan the publication calendar and to review the channel's performance. No data about other users, viewers, channels or videos is collected or stored.
  • Sharing. We do not sell, rent or share any YouTube API data with anyone. We do not use it for advertising, profiling or any purpose other than operating the Bolita Lab channel.
  • Retention. Locally stored API data is kept for as long as it is useful to operate the channel and can be deleted by the owner at any time. Refresh tokens can be revoked at any time at myaccount.google.com/permissions (Google security settings page), which immediately stops all API access.

4. This website

This website is a static page. It sets no cookies, has no analytics, no tracking and no forms. It is hosted on GitHub Pages; GitHub may log standard server data (such as IP addresses) as described in GitHub's privacy statement.

5. Children

The website and the API client are not directed to children and do not knowingly collect information from anyone under 13.

6. Changes and contact

We may update this policy; the effective date above will change accordingly. Questions: sinostrozadev@gmail.com.
